# 架空世界星空生成

为一个架空世界生成一整片物理上自洽的星空：从银河系里的恒星、尘埃、星团出发，算出从这颗行星上某个地点看到的夜空，并配一个可以在浏览器里看的观星器。

整体分三层：

- **物理层**：宇宙里实际有什么，写在真值星表里。
- **观测层**：这个世界的人用肉眼或早期望远镜能看到、能测到什么，写在世界内星表里，带测量误差。
- **文化层**：星座、命名等，还没做。

## 准备

需要 Python 3 和 numpy、Pillow、PyYAML。项目自带的 `.venv` 已经装好。

```bash
.venv/Scripts/python.exe -m pip install numpy pillow pyyaml
```

## 生成

```bash
.venv/Scripts/python.exe generate.py
```

按配置的深度（约 10.6 等）生成，约 3 分钟，结果写到 `out/`。

```bash
.venv/Scripts/python.exe generate.py --mag-limit 6.5
```

只生成肉眼可见的星，十几秒，用来快速验证。

```bash
.venv/Scripts/python.exe generate.py --overrides-only
```

改完 `overrides.yaml` 后用这个，全深度约半分钟。不重新采样，从完整运行时存下的快照（`out/stars_base.npz`）重新应用覆盖并导出；只有超新星遗迹变了才会自动重画背景。

```bash
.venv/Scripts/python.exe generate.py --export-only
```

只改了事件或输出相关的配置时用：根据 `out/stars_raw.npz` 重写事件、星表和观星器数据。

```bash
.venv/Scripts/python.exe generate.py --background-only
```

只重画背景贴图（比如调了 `remnant_render_boost`）。

改了星系、尘埃、恒星族群这类参数，还是要完整运行。

其他选项：

- `--no-background`：跳过背景贴图，最耗时的一步。
- `--bg-compute W H`：背景的积分分辨率，默认 2048×1024，输出时放大到配置的分辨率。
- `--config`：换配置文件。
- `--out`：换输出目录。

同一份配置加同一个种子，生成的结果完全相同。改生成深度时，已有的星和编号不变。

## 物理合理性检验

```bash
.venv/Scripts/python.exe validate.py
```

读 `out/` 里已经生成的结果（不重新生成，约 2 秒），逐项给出"通过 / 警告 / 不通过"：

- **自洽**：同一颗星的量之间对得上，比如光度 = 4πR²σT⁴、星等链、开普勒定律、演化阶段与年龄、双星不相撞、食双星几何、星团同龄。
- **单星合理**：和真实恒星的经验关系比，比如主序质量–光度关系、各光谱型的绝对星等、白矮星的亮度和半径、各类变星所在的区域、造父变星周光关系、光度上限。
- **全天统计**：和真实天空比，比如各星等的星数、光谱型构成、巨星比例、银纬集中度、肉眼变星数、白矮星亮度。
- **手动覆盖**：`overrides.yaml` 改过的星，偏离演化轨迹的单独列出（只警告）。

报告写到 `out/validation_report.md`，赫罗图画到 `out/validation_hr.png`。真实天空的参考数是近似值，容许范围放得比较宽。

## 看星空

```bash
.venv/Scripts/python.exe -m http.server 8765
```

然后打开 <http://localhost:8765/viewer/>。必须经过本地服务器，直接双击 html 读不到数据。

| 操作 | 作用 |
|---|---|
| 年份 / 日期 / 时刻 | 设定观测时间；年份可以往前推几千年，看岁差和自行 |
| 播放、1 分/10 分/1 日每帧 | 让时间走起来；空格键暂停或继续 |
| 拖动 / 滚轮 | 转视角 / 缩放 |
| 点击星 | 显示真值信息：距离、光谱型、几合星、变星、所属星团 |
| 肉眼 / 望远镜（T） | 切换极限星等和视场 |
| 地面透视（G） | 地面变半透明，能看到地平线下的天空 |
| 搜索恒星（F） | 按星等、距离、光谱型、光度级、演化阶段、变星类型、几合星、星团、温度、质量、年龄、绝对星等、消光、颜色组合筛选；结果在天上用方框标出，点一行就转过去 |
| 银河、星点滑块 | 调背景和星点亮度 |
| 复选框 | 地平和赤道网格、黄道、深空天体、大气消光、月亮、客星/彗星、亮星编号 |

左下角列出亮于 2 等的客星（含故事当下之后的"未来"），点一下就跳到那一天、转到那个方向。

画面会随时间变化：

- 暮光和月光会让能看到的星变少；白天和满月时银河会被淹没。
- 变星按光变曲线变亮变暗。
- 超新星、新星和大彗星在对应日期出现。

| 文件 | 内容 |
|---|---|
| `truth_catalog.csv` | 真值星表，每颗恒星一行（多星系统的成员各占一行）：位置、距离、质量、年龄、演化阶段、光谱型、温度、光度、半径、自身亮度、变星、消光，伴星还有轨道（周期、半长轴、偏心率、倾角、角距、能否分开） |
| `truth_systems.csv` | 每个恒星系统一行：成员列表、合成亮度、合成光谱型 |
| `in_world_naked_eye.csv` | 世界内肉眼星表：带测量误差的亮度、颜色、位置 |
| `in_world_telescope.csv` | 世界内望远镜星表：望远镜分得开的伴星单独列 |
| `naked_eye_epoch_*.csv` | 历史年代的肉眼星表（年份在配置里设） |
| `events.csv` / `.json` | 超新星、新星、大彗星的时间线（默认 −8000 到 2000 年；`future` 列标出故事当下之后的） |
| `dso_catalog.csv` | 深空天体：星团、星协、星云、球状星团、外星系、超新星遗迹 |
| `stars_raw.npz`、`dso_raw.npz` | 全部内部字段，供 `--export-only` 和分析用 |
| `stars_base.npz`、`dso_base.npz`、`names_base.json` | 覆盖之前的快照，供 `--overrides-only` 用 |
| `background_linear.npy` | 背景的线性亮度 |
| `viewer/` | 观星器读的数据：星点二进制、星的信息、天空参数、背景贴图 |

## 配置

所有参数都在 [starfield_config.yaml](starfield_config.yaml)，互相耦合的参数放在同一节：

| 节 | 内容 |
|---|---|
| `sky_clock` | 卫星、岁差、宿 |
| `galaxy` | 星系朝向、盘、核球、旋臂、背景银河 |
| `dust` | 尘埃、暗云、湍流起伏、消光 |
| `stars` | 初始质量函数、恒星形成历史、本地恒星密度 |
| `observing` | 观测地点、肉眼与望远镜极限、星表误差 |
| `clusters` | 星团与星协 |
| `evolution` | 演化与脉动变星 |
| `multiplicity` | 双星、三合星、食变星 |
| `events` | 超新星、新星、彗星的频率 |
| `landmarks` | 地标约束，例如最亮星要多亮、要不要红超巨星 |
| `output` | 输出目录、要额外输出的历史年代、背景贴图分辨率 |

写成 `auto` 或 `derived` 的项由程序推导。

## 手动覆盖

想改某颗星，就把 [overrides.example.yaml](overrides.example.yaml) 复制成 `overrides.yaml`，按编号写操作，然后运行 `--overrides-only`。编号可以在观星器里点星或用搜索器查到。

编号规则：单星是 `xxxxxxxxxxxx-NNN`；多星系统的成员在后面加 A/B/C。A 是原本最重、最先演化的那颗，它先变成白矮星或巨星时可能比 B 暗；B 绕 A 转，C 绕 A+B 转。写系统编号（不带字母）或 `…A` 都是改主星；写 `…B` / `…C` 是改伴星，可以改名、改质量或光谱型（年龄跟随系统）、删除。

- **改星**：星名、光谱型（例如写 `M1Ib`，程序会反推出演化成这个光谱型的质量和年龄）、演化阶段、质量、年龄、温度、光度、绝对星等、距离、方向，也可以直接给目标视星等。
- **指定超新星**：某颗星在某年爆发。
  - 爆发年在故事当下之前：当下的星表里就没有这颗星了，留下遗迹。
  - 爆发年在之后：它现在还在天上，观星器里到那天会爆发，然后消失。
- **删星、加星**：加星时可以用光谱型来指定。

改动后会重算演化、变星、食变星、双星合成亮度和消光。

## 代码结构

```
generate.py          入口
starfield/
  config.py          读配置、推导 auto 项
  hashrng.py         计数器式哈希随机数（结果与生成顺序、深度无关）
  coords.py          银道 → 黄道 → 赤道 → 地平，岁差
  galaxy.py          星系盘、旋臂、自转
  dust.py            三维尘埃场：平滑盘 × 湍流起伏 + 丝状尘埃云
  evolution.py       简化恒星演化、颜色、光谱型
  population.py      分层采样生成场星
  multiplicity.py    双星、三合星、食变星
  variables.py       脉动变星
  clusters.py        星团、星协、深空天体
  landmarks.py       地标约束
  overrides.py       手动覆盖层（改星、按光谱型反推、指定超新星）
  observe.py         消光、视星等、天球位置、双星可分辨性
  events.py          超新星、新星、彗星时间线
  background.py      全天背景贴图
  export.py          所有输出文件
validate.py          物理合理性检验
viewer/
  index.html, app.js WebGL2 观星器，无外部依赖
```

设计决策、已定参数、当前结果和待办见 [HANDOFF.md](HANDOFF.md)。
